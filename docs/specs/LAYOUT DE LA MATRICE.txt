2.COMPORTEMENT SPÉCIAUX
TRANSPOSE 
T_

Lorsque la touche est pressée, l’action est effectuée.
Si la touche est à nouveau pressée, l’action est à nouveau effectuée : l’effet est cumulatif, dans la limite du protocole midi : il n’est pas possible d’atteindre au delà de de N_sol9 ou en deçà de N_do1m.

ALTERATION
A_

À la première pression : 
Inversion bécarre/dièse de toutes les notes correspondantes au code (+1 demi ton pour les bécarre, -1 demi ton pour les dièses) 
À la seconde pression : 
Inversion bécarre/bémol de toutes les notes correspondantes au code (par rapport au keymap de base, pas à partir de la première altération)(-1 demi ton pour les bécarre, + demi ton pour les bémol) 
À la troisième pression : 
Retour au keymap original. 

En cas de conflit d’état,la dernière pression prime.

Code : 
A_do
A_re
A_mi
A_fa
A_sol
A_la
A_si


Exemple :

A_fa est pressé. 

Sur l’ensemble du keymap, on retrouve : 

N_fad4 N_mi4 N_mi6 N_fad6
N_fa3 N_fa5
N_fad3 N_mi3 N_mi5 N_fad5
N_fa2 N_fa4 
N_fad2 N_mi2 N_mi4 N_fad4
N_fa1 N_fa3

(Il faut intégrer les N_mi, puisque fa bémol = fa-1 demi ton = mi. Mi est donc concerné par la transposition du Fa)

Cela devient : 

N_fa4 N_mi4 N_mi6 N_fa6
N_fad3 N_fad5
N_fa3 N_mi3 N_mi5 N_fa5
N_fad2 N_fad4 
N_fa2 N_mi2 N_mi4 N_fa4
N_fad1 N_fad3

A_fa est à nouveau pressé. L’état de fait précédent :

N_fa4 N_mi4 N_mi6 N_fa6
N_fad3 N_fad5
N_fa3 N_mi3 N_mi5 N_fa5
N_fad2 N_fad4 
N_fa2 N_mi2 N_mi4 N_fa4
N_fad1 N_fad3

Devient : 

N_fad4 N_fa4 N_fa6 N_fad6
N_mi3 N_mi5
N_fad3 N_fa3 N_fa5 N_fad5
N_mi2 N_mi4 
N_fad2 N_fa2 N_fa4 N_fad4
N_mi1 N_mi3

A_fa est pressé une troisième fois. Retour à l’état initial : 

N_fad4 N_mi4 N_mi6 N_fad6
N_fa3 N_fa5
N_fad3 N_mi3 N_mi5 N_fad5
N_fa2 N_fa4 
N_fad2 N_mi2 N_mi4 N_fad4
N_fa1 N_fa3
